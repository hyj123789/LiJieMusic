# 这是一个音乐播放器（LIJIeMusic）
利用网易云的接口完成了大部分功能的实现

由于最开始计划并不完善，本来想着完成一个单activity多fragment的标准架构的，但是在后续的实践中发现了诸多问题，以至于TheRouter都没有完美的运用起来...
## 接下来先介绍一下本app的基本使用：
  - 进入app会先进行登录注册的要求（验证码登录，扫码登录，游客登录（但游客登录由于很多功能需要登录后才能体验，所以会有很大部分的功能无法体验））
  - 主页部分有一个底部导航栏（可以完成页面的切换，共四个页面）与顶部导航栏（可以进入设置退出登录，查看动态，以及搜索歌曲的功能等等）
  - 主页：有歌单与歌曲，点击歌单可以查看歌单详情（点击任意一首歌都可以加载该歌单的全部歌进入播放歌单），点击歌曲可以播放（点击播放img可以立刻播放，点击封面可以加入下一首）
  - 搜索主页面：有歌单（与上面一样的功能）和搜索按钮点击进入搜索页面，还有5个小图标，点击会有底部弹窗查看数据，但是5个图标的内容均没有实现点击功能
  - mv页面：有三种mv模式可以左右滑动查看，以及前两种模式可以筛选关键词点击空白部分弹窗消失并自动刷新，以及触底自动刷新更多mv
  - 我的页面：有我喜欢的歌以及我的歌单，还有头像与海报等个人信息，点击我的歌单的封面可以更改为本地照片
  - 所有页面的最下面有一个迷你播放器，可以查看正在播放的歌以及播放列表（播放列表可以切歌，清除所有，清除单曲，单曲循环，随机播放，顺序播放，完成了本地存储，再次打开应用之前歌单的歌会缓存出来）
  - 点击mini播放器的封面可以进入大播放器，完成了播放器的基础功能，上一首，下一首，暂停，播放，封面转动，喜欢的，和音质选择的功能实现
  - 点击旋转封面可以看见歌词以（大部分歌曲有逐字歌词，可以上下滚动查看歌词，点击歌词可以跳转到虚线处的歌词处播放）
  - 点击播放歌单可以选择播放模式，有单曲，随机，顺序，也可以删除单歌，和清除播放歌单的全部歌曲
  - 点击右上角的分享图标可以进入分享页面，分享到网易云动态里（限制140字），点击臻品母带可以选择音质切换（共三种）
  - 点击评论按钮，可以进入评论区，可以看三种模式的评论，还可以查看楼层评论，以及触底自动刷新更多评论可以点击评论按钮发送自己的评论（需要前往最新评论查看）
  - 在封面出右滑或者点击详情图标进入歌词百科有回忆坐标与相关歌曲歌手信息
## 主要模块
由于最开始没有确定的规划，所以很多模块存在共创的情况，这里只详情介绍我写过或者优化过的模块，全由ljh书写的模块简略介绍

主要分为三个大模块，app大模块（最高层），core大模块（最底层），feature大模块（功能模块）
### app大模块
- 该模块主要啊完成了对大部分fragment的布局归属，以及启动应用的初始化（获取本地缓存数据，初始化音乐连接等等）
- ui界面主要完成了一个activity框架的搭建，底部导航栏以及侧滑的抽屉
### core大模块
该大模块分为5个小模块，主要完成基础的底层连接，减少代码冗余，以及全局管家的建立
#### 1. base模块，

完成了对baseactivity和basefragment和baseviewmodel的书写，后续模块只需继承即可，不需要重复冗余代码，还完成了PlaterManager大管家的书写（SongDetail，MediaControllerHelper用于辅助大管家的功能实现），可以在任意模块调用音乐播放管家用于对音乐的操作

#### 2. **model模块**
完成了登录后用户个人信息的存储方便全局调用

#### 3. **net模块**
该模块实现了对网络请求api调用的封装，之后只需要简单的调用该模块的封装逻辑就可以实现网络请求，有根据登录状态自动加cookie的功能

#### 4. **therouter模块**
该模块完成了therouter跳转字段的书写（但由于结构的原因，大部分没有用起来）

#### 5. **util模块**
该模块完成了对全局工具类的书写，例如弹窗等等

### feature大模块
该模块完成了对app功能的实现，ui设计与用户交互逻辑的实现，但是该模块较多较杂，并没有很好的分好模块
#### 1. **comment模块**
该模块啊实现了正在播放分区评论区的查看，完成了可以查看三种模式下的评论内容，并有触底刷新等功能（全部评论的触底刷新会无视你的参数加载所有的评论），还利用扁平化设计完成了层评论的展开与关闭

## 重要的知识点
在这次的app构建中我学习到了很多新的知识点，也熟练了更多已经学过的知识点

我对于rv的使用更加的流畅了，理解也更加深入了，以前用过线性布局，这次用到了网格布局等等，对于协程的使用更加深入且顺手了，了解到了一些以前不知道的接受数据流的方法，比如利用combin一起接收数据流，以及也更了解Retrofit网络请求了，在上一次的51考核中并没有使用过网络请求，这一次也算是上手操作了一次了

我也学习到了很多新东西：比如LinearSnapHelper吸附类的使用在rv上让我的滚动齿轮得以实现，比如图片加载的glide的使用，以及音乐播放器的导入和使用原来并不难，再比如动画的初次尝试，再ai的辅助下也实战了一次让我更了解动画的相关使用，以及滑动冲突的处理对父布局的拦截让子布局处理滑动事件，还有多模块合作的很多注意事项和therouter的使用，和deepLink跳转
